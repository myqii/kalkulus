Fundamental
|x - a| ≤ r
Mencari ambang rentang interval observasi (x) berdasarkan target (a) dan error toleransi (r).
  • x = Observasi
  • a = Target
  • r = Toleransi
Parameter Definition
Visualisasi Fungsi E(x) = |x - a|
Hasil
|x - 30| ≤ 2
Step 1: Ekspansi
-r ≤ x - a ≤ r
Step 2: Substitusi
-2 ≤ x - 30 ≤ 2
Step 3: Nilai Ruas
30 - 2 ≤ x ≤ 30 + 2
28 ≤ x ≤ 32
